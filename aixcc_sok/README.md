## What this is

A citation-anchored reference scaffold for a Cyber Reasoning System (CRS) based on the
consensus architecture of the 7 finalist teams in DARPA's AIxCC (2023–2025).

This is **not** a runnable CRS. It is an interface scaffold showing:
- Where each component goes (§-cited stubs)
- Why each design choice was made (every default justified by paper data)
- What must be implemented (all `NotImplementedError` stubs describe exactly what they need)

## Default architecture choices (justified by paper)

| Component | Default | Justification |
|-----------|---------|---------------|
| Agent architecture | Multi-Agent | TB (2nd place) — best simplicity/performance |
| SARIF strategy | PoV-centric | AT (1st), TB (2nd) used this; most conservative |
| LLM reflection | Enabled | 5/7 teams; reduces patch loop failures |
| Minimal patch set | Enabled | 4/7 teams; prevents duplicate submission penalties |
| Pipeline cooperation | Bidirectional | AT (1st) + TI (3rd) + SP (5th) used both directions |
| PoV submission | ASAP + dedup | All 7 teams; time-decay makes early submission always better |
| Bundle update | Until deadline | Free updates, no time-decay; always rebundle |
