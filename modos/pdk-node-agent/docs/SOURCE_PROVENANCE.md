# Source Provenance

This workspace was co-drafted from the complete reverse-ordered Gemini specification packet and the current Pleiades architecture set:

- Unified Architecture and Construction Canon v2;
- prior Unified Architecture revision retained for lineage;
- Operating Domain System Blueprint;
- Upper-Domain Supercluster Kernel / PDK Blueprint;
- Context Immunity Blueprint;
- ODS Ancestry and Failure Atlas.

The screenshots and full source-paper snapshots are retained in the private drafting/resource lineage rather than duplicated into this public implementation branch. The normalized implementation requirements are preserved in `GEMINI_CO_DRAFTER_SPEC.md`, and the architectural decisions introduced during reconciliation are preserved in `DRAFTING_SYNTHESIS.md`.

## Provenance rules

1. The Unified Canon v2 governs conflicts.
2. Later explicit steward ADRs may refine canon but must remain reviewable.
3. Historical papers, branches, transcripts, and backups supply evidence; they do not silently override current canon.
4. Generated Rust, schemas, and configuration remain traceable to a requirement or documented synthesis decision.
5. Public artifacts do not disclose private repository paths, raw evidence, secrets, or private RYZ implementation details.
6. Static validation is recorded separately from compilation and live-system validation.
